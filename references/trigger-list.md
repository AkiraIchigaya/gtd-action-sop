# 通用型触发清单（唤醒词库）

用于安排阶段"查看关键词提示 -> 收集"以及每日复盘回忆今日事项，逐类扫描大脑中遗漏的闪念。

## 工作维度

- **项目**：进行中的项目、待开始的项目、待评估的项目。
- **答应别人的事**：老板、合作伙伴、顾问、教练、战略合作伙伴、同事、下属、组织内其他成员、其他专业人士、客户、其他组织。
- **联系**：电话、电子邮件、语音邮件、传真、信件、备忘录、短信、社交媒体内容。
- **待完成的文稿**：报告、评估、审查、提案、文章、营销材料、说明书、摘要、会议纪要、重写和编辑、状态报告、对话和沟通跟踪。
- **阅读**：图书、期刊、文章、打印文件、网站、博客、RSS 订阅、播客。
- **财务**：现金、预算、资产负债表、损益表、预测、信用额度、应付账款、应收账款、备用金、银行、投资者、资产管理。
- **计划**：愿景、短期目标、长期目标、商业计划、营销计划、财务计划、即将到来的事件、演示文稿、会议、出差、旅行、假期、商务出差。
- **组织发展**：组织结构图、重组、权力线、职位描述、设施、新系统、领导力、变革倡议、继任计划、文化。
- **市场营销**：活动、材料、公共关系。
- **行政管理**：法律问题、保险、人员、人员配备、政策/程序、培训。
- **员工**：招聘、解雇、评估、沟通、员工发展、士气、反馈、薪酬。
- **设备**：移动设备、手机、计算机、软件、数据库、电信设备、办公设备、打印机、传真、文件归档、存储、家具、装置、装饰品、办公用品、名片、文具、个人/电子组织器。
- **销售**：客户、潜在客户、销售线索、销售流程、培训、建立关系、报告、关系追踪、客户服务。
- **会议**：即将到来、需要设置或请求、需要接受简报。
- **等待**：信息、委派的项目/任务、项目的组成部分、对通讯的回复、对提案的响应、对问题的回答、提交需要回复/报销的事项、工单、继续或完成项目所需的外部行动（决策、变更、实施等）、产品订单。
- **职业发展**：培训、研讨会、需要学习的事物、需要了解的事物、需要发展或练习的技能、需要阅读的书籍、研究、正式教育（许可、学位）、职业研究、简历。
- **衣着**：职业着装。
