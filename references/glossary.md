# 黑话表

作者（自称"逗总"）给每套流程起了名字，看起来花哨，但每个都对应一个具体功能。

## 四个"包"（成套的动作集合）

| 名字 | 管什么 | 什么时候用 |
|---|---|---|
| **逗总收集包** | 怎么把东西**捞进来**：闪念、漏记、环境、关键词提示、角色责任、终极目的 | 全局一条 + 安排段前六条 |
| **逗总决策包** | 怎么**清空收集箱**：按决策流程图逐条判断去处 | 安排段 |
| **逗总校准包** | 怎么让清单**和现实对齐**：更新动作/项目清单、修愿望箱 | 安排段 + 复盘段 |
| **逗总行动包** | **执行**时的动作库：挑当下最合适的、处理紧急、加等待指令 | 执行段 |

## 四个"法"

| 名字 | 管什么 | 一句话 |
|---|---|---|
| **刚性截止法** | 日历 | 只有"不能改期"的事才进日历（别人的会、法规期限、承诺日） |
| **指令打包法** | 打包清单 | 把一串动作预先打包成模板，符合情景时整包调用 |
| **游戏小人法** | 时间块 | 按时间块派活：下指令 → 预估时间 → 321 行动 → 开启倒计时 → 执行 → 静止 |
| **逗总打卡术** | 打卡清单 | 成功 +1、失败 −1，用积分而不是"连续天数" |

## 两个"块/箱"

| 名字 | 说明 |
|---|---|
| **逗总时间块** | 一天的执行单元：填写时间段（附带截止 + 该时段任务），执行时按时间块派活 |
| **愿望箱** | "以后做"的东西的去处（例：要不要去迪士尼）；安排段还有一条"查看愿望箱 → 收集箱" |

## 决策流程图里的四个去处

| 名字 | 收什么 |
|---|---|
| **垃圾桶** | 没用了 |
| **收纳箱** | 不用做（但要留着） |
| **愿望箱** | 以后做 |
| **草稿纸** | 想不清楚时，回去写、改指令（拆解用的中间地带） |

## 术语的用法

**"所属"这一列不是为了好看**。它的作用是：当某个动作执行起来别扭时，
你只需要改**对应的那一个包**，而不是重新设计整张表。
改完其他包不受影响 —— 这也是"删了不影响"能成立的原因。
