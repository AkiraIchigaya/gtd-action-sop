# 完整样例（few-shot）

三组从输入到输出的完整走查，用于对齐指令颗粒度与输出裁剪。样例中的姓名、项目名仅为示意。

## 样例 1：整理收集箱（含目标确认与等待事项）

**用户输入**：

```
收集箱：
1. 下周交策划案
2. 电蚊拍没电了
3. 想学 Blender
4. 张三还没把报价单给我
5. 上个月的报销单还没交
6. 那个旧充电器坏了，扔了吧
```

**Agent 处理过程**：

1. 第 1 条：目标有多种标准（按时提交 / 让客户满意 / 拿下项目），且截止日期不明 -> 暂停，先问目标与具体日期。
2. 第 2 条：目标"电蚊拍恢复可用"；插线 2 分钟内可完成 -> 立刻做，签完不进清单。
3. 第 3 条：无明确时限、无近期投入 -> 愿望箱，不拆解。
4. 第 4 条：等待事项，但需要宿主项目。当前无对应项目 -> 先问"报价单是为了哪个项目/目标"，确认后建项目再挂等待指令。
5. 第 5 条：报销通常有刚性截止 -> 问清截止日期，有则进日历，无则作为普通动作。
6. 第 6 条：涉及实物丢弃 -> 一句话确认后再丢，Agent 不擅自处置。

**输出**：

```markdown
> [!tip] 需要你确认 2 件事
> 1. 「下周交策划案」目标选哪个：按时提交 / 让客户满意 / 拿下项目？具体提交日是几号？
> 2. 报销单有没有截止日期？
> 3. 报价单属于哪个项目？（没有的话我先建一个项目再挂等待）

### 动作清单
- [ ] 提交上月报销单
- [ ] 在群里通知张三补报价单（若需正式催办则改为等待指令）

### 项目清单
- **本周提交策划案**（待你确认目标后定稿）
  - [ ] 下一步：列出策划案三级大纲

### 愿望箱 / 收纳箱
- 愿望箱：学 Blender

### 立刻做
- [ ] 给电蚊拍插上充电线
- [ ] 确认旧充电器无人需要后丢入回收箱
```

**要点**：目标类问题一次问清、合并提问，不逐条来回打断；能 2 分钟做完的直接给"立刻做"，不污染清单。

## 样例 2：问"现在该做什么"（信息不足先问）

**用户输入**：`我现在该干嘛？`

**Agent 处理**：缺少剩余时间、精力、环境三要素 -> 先一句话追问，不硬推。

```
还需要 3 个信息才能挑得准：现在到下一个节点还有多久？精力是满格/一般/快没电？人在哪（办公室/宿舍/路上）？
```

**用户补充**：`还有 40 分钟，精力一般，在宿舍`

**输出**：

```markdown
> [!tip] 当下唯一推荐指令
> - [ ] 整理下周策划案的三级大纲（预估 30 分钟 | 适配：宿舍安静、精力一般，不需外出）

备选（若不想动脑）：给电蚊拍插上充电线 + 清空手机备忘录 3 条。
```

**要点**：只推 1 条，备选最多 1 条且明显更轻；推荐理由要对应三要素。

## 样例 3：每日复盘（不擅自设评分线）

**用户输入**：`今天复盘一下。做完了：写周报、交报销单。策划案大纲没写完。`

**输出**：

```markdown
### 今日复盘与校准
- 已完成勾销：
  - [x] 写周报
  - [x] 提交上月报销单
- 未完成：策划案大纲 -> 该项目仍非空，已保留 `下一步：补完大纲剩余 2 节`

### 项目清单
- **本周提交策划案**
  - [ ] 下一步：补完大纲剩余 2 节（约 25 分钟）

### 趋势打卡
- 今天的达标标准由你定：写周报 + 交报销单算达标吗？
- 你回答"算" -> 记 +1（累计 4）；回答"不算" -> 记 -1（累计 2）。Agent 不预设阈值。
```

**要点**：复盘的三个动作固定为"勾销现状 -> 补下一步 -> 按需打卡"；打卡成败标准必须由用户给出，Agent 只负责记录与趋势提示（高点更高、低点不破前低）。
