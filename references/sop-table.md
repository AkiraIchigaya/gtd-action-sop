# SOP 四阶段三列总表

整套流程按时间流转分为**全局、安排、执行、复盘**四大区块，每条行动包含**触发条件、具体行动、所属模块（必选 vs 插件）**三列。

## 模块分类说明

- **必选包（核心闭环，不可删减）**：收集包、决策包、行动包、校准包。
- **插件包（按需启用，删减不影响主流程）**：指令打包法、刚性截止法、时间块、游戏小人法、打卡术。
- **模块归属约定**：愿望箱回流在时间上属**安排**阶段，在模块上归**决策包前置动作**（它服务于清空收集箱），不属于复盘环节。

## 初次配置与系统重启

### 初次配置顺序

1. 先按**安排**前 5 条收集动作做一次全面大扫除（初次可能收集 50-100 条闪念，属正常现象）。
2. 跳过"查看愿望箱"（此时为空）。
3. 用决策流程图逐条清空收集箱。
4. 为所有项目清单补全下一步指令；按需配置打包清单与明日时间块。

### 中断后的重启顺序

若因懈怠或忙碌中断了一段时间，清单已与现实脱节：

1. **先做复盘**：更新动作清单、项目清单、日历与打包清单，把已失效或已完成的清理掉，重新对齐现实。
2. **再做安排**：补收集、查看愿望箱移回收集箱、走决策流程图清空收集箱、补下一步指令、排明日时间块，次日即可恢复正常执行。
