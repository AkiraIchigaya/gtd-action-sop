# 五大可选插件包细则

所有插件包均可在不影响主流程的前提下按需开启或关闭。

## 1. 指令打包法（批量处理与等待管理）

- **适用场景**：任务数量多、需要按同一情境/对接人批量处理，或需要集中追踪委托给别人的事。
- **安排阶段**：为可一起执行的指令打上标签或建`打包清单`（例如"IT部门""外出采购"）。强烈建议建立一张**等待打包清单**，把所有委托出去的等待指令聚合到一起（原项目清单内仍须保留或关联对应等待指令，不可抽空原项目）。
- **执行阶段**：符合对应情境时，直接打开打包清单一次性处理；定期扫一眼`等待打包清单`，查看哪些快到期需要催促。
- **复盘阶段**：同步更新打包清单，打勾、修改或删除已取消项。若使用手账或纸质笔记本，需重新抄写一张新的打包清单，不可在原位置涂改删除。
- **删减条件**：若任务很少，点几下就能看清，可不用此插件。

## 2. 刚性截止法（恢复截止日期的严肃性）

- **核心区分**：
  - **刚性截止**：真正的 deadline，错过了会出严重后果（如还信用卡、论文答辩、固定点开会）。必须标注日期并加入`日历`。
  - **弹性截止**：仅仅是自己希望完成的日期（如"背 30 个单词"）。**绝不标注日期**，防止假截止日期导致对小红点麻木（劣币驱逐良币）。
- **执行阶段**：每天参照`日历`，确认当天是否有必须完成的刚性截止任务。
- **复盘阶段**：同步更新日历，确保与现实一致。

## 3. 逗总时间块（留白式人性化行程表）

- **核心结构**：把一天划分为约 6 个时间块（节点可根据个人作息自定义，例如 07:30 起床、09:00 早饭、12:00 午饭、15:00 下午茶、18:00 晚饭、21:00 夜间放松）。**关键原则：每个时间块的节点本身必须是放松时间**，形成"做完这一块就能休息"的正向心理暗示。实体使用建议用纸笔并竖在眼前，方便腾挪且随时可见。
- **安排阶段**：只在时间块里填入两类事，保留大量空白：
  1. 明日的**刚性截止**任务；
  2. 1-2 个**成就任务**（做了就会觉得今天没白过、对自己满意的事，可分摊到多个块；若刚性任务极多也可不排成就任务）。
- **执行阶段**：
  - 时间块为空白时 -> 按行动包从动作/项目清单挑最合适的事做（或合理休息）。
  - 时间块内有任务时 -> 优先做完该任务，期间可能出现 3 种情况：
    1. **任务完成，时间块未结束**：余下时间继续从动作/项目清单挑指令做。
    2. **时间块结束，任务未完成**：将该任务挪到后面新的空白时间块，不硬撑。
    3. **出现紧急任务**：触发行动包紧急分支（紧急且立刻马上做；紧急但暂缓高亮标注稍后做）。

## 4. 游戏小人法（专治无意识浪费时间）

- **适用场景**：容易走神、不知不觉时间流逝、拖延启动困难。
- **启动节拍**：把自己想象成游戏里的小人，严格执行闭环：`下指令 -> 预估时间 -> 默念 3-2-1 行动 -> 开启可见倒计时 -> 执行 -> 完成后静止`。
- **关键机制**：
  - **可见倒计时**：用滴答响或摆在眼前一眼可见的计时器，靠时间流逝节奏带动身体加速；藏在看不见的手机后台无效。
  - **完成后静止**：像木头人一样刻意静止，利用"静止的不适感"逼迫自己立刻下达下一条有意识的指令，防止顺手开始无意识刷手机。
- **执行中的 3 种情况**：
  1. **倒计时结束，任务未完成**：重新预估一段新时间，继续倒计时执行。
  2. **任务提前完成，倒计时未结束**：立刻按掉倒计时，开启下一条新指令。
  3. **出现外部干扰**：结束当前任务，立刻为突发任务下达新指令并重新计时。
- **注意事项**：全程保持高度有意识状态非常耗费精力（无冥想基础者通常保持 30 分钟已属不易），将其视为**专注力练习**而非全天候强制要求。

## 5. 逗总打卡术（股票折线趋势打卡）

- **适用场景**：用普通打勾法容易因为偶尔断签、偷懒而心态崩溃放弃的人。
- **复盘规则**：画日期-次数折线图（或记录累计净值）：今天成功做到向上 **+1**，失败/没做到向下 **-1**。**注意：每日成功或失败的达标判定标准由用户自定，原教程未规定统一阈值，Agent 不得擅自设定评分线。**
- **趋势判断原理（源自股票上升趋势）**：
  - 上升趋势只需满足两个特征：**高点比前高更高，低点不比前低更低**。
  - 偷懒下滑几天没关系，只要在滑到接近前一个低点时警惕拉起，不跌破前低；并在反弹接近前一个高点时有意识地突破前高，整体趋势就是向上的。
  - 若低点未破前低、高点也未破前高，则处于**横向震荡**状态，需要主动挑一个突破点往上拉升。
