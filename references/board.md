## 决策流程图（清空收集箱的规则）

`根据决策流程图 → 清空收集箱` 里的那张图，逐层判断：

```
收集箱
  │
  ① 做？不做？
  ├─ 没用了   → 垃圾桶
  ├─ 不用做   → 收纳箱
  ├─ 以后做   → 愿望箱
  └─ 做 ↓
  ② 目标是什么？  ──(目标 → 项目名)──→ 项目清单
  │
  ③ 做什么可实现？  ──(改指令)──→ 草稿纸
  │
  ④ 两分钟？
  ├─ 是   → 立刻做
  ├─ 一条 → 动作清单
  └─ 多条 → 项目清单
```

要点：
- **第一刀是"做不做"**，三个"不做"各有去处：没用了→垃圾桶、不用做→收纳箱、以后做→愿望箱。
- 决定要做之后**先问目标**，目标直接变成项目名 → 进项目清单。
- 再问"做什么可实现"，拆不动就回**草稿纸**去写（改指令是回环）。
- **两分钟法则**收尾：两分钟内能做完就立刻做，不再入清单。

## 时间块（执行段的引擎）

```
下指令 → 预估时间 → 3-2-1 行动 → 开启倒计时 → 执行 → 静止
```

- 计时器是**实体**的（厨房电子计时器），不是手机。
- 「静止」= 到点就停，是结束不是失败。
- 时间块表按时间点手写（07:30 起床 / 09:00 早饭+写文章 / 12:00 午饭 / 15:00 下午茶 / 18:00 晚饭+做封面）。

| 情况 | 动作 |
|---|---|
| 时间块是空白 | 从动作清单挑一条填进去 |
| 任务做完但时间块没结束 | 再从动作清单拿一条，不许提前放空 |
| 时间到、还在状态 | 继续执行，不打断 |
| 时间到、没做完 | 重新计时，再设一个块 |

## 游戏小人法：四条设计理由（视频原话）

| 设问 | 原话 |
|---|---|
| 为什么要给自己下指令 | 「觉得时间不知不觉过去了」「自己清楚自己在干什么」 |
| 为什么要设置倒计时 | 「不是一个真的 deadline」「带动身体的节奏」「避免分心」 |
| 为什么要默念 321 行动 | 「像火箭发射这样」「让自己赶紧去做」 |
| 为什么要静止 | 「如果你不是这种静止的」「又会失去意识了」 |

推论：**倒计时不是压力，是节拍**；**静止不是休息，是保持清醒**。
